Реализация библиотеки string.h с дополнительными функциями на языке C (стандарт C11).

## 📋 Описание

Проект представляет собой кастомную реализацию стандартной библиотеки string.h с добавлением функций `sprintf`, `sscanf` и специальных функций обработки строк. Разработан в рамках обучения в **Школе 21 (School21)**.

## 🚀 Особенности

- Полная реализация стандартных функций string.h
- Дополнительные функции обработки строк (вдохновленные C# String)
- Частичная/полная реализация sprintf и sscanf
- Кросс-платформенная поддержка (Linux/macOS)
- Покрытие unit-тестами (>80%)
- Сборка через Makefile

### 🔧 Функции

#### Стандартные функции string.h

- **Поиск и сравнение**: `memchr`, `memcmp`, `strchr`, `strncmp`, `strstr`, `strpbrk`
- **Копирование и заполнение**: `memcpy`, `memset`, `strncpy`
- **Конкатенация и длина**: `strncat`, `strlen`, `strcspn`
- **Обработка ошибок**: `strerror`

#### Форматированный ввод/вывод

- `sprintf` - форматированный вывод в строку
- `sscanf` - форматированный ввод из строки

#### Специальные функции (C# String inspired)

- `to_upper` - преобразование в верхний регистр
- `to_lower` - преобразование в нижний регистр
- `insert` - вставка подстроки
- `trim` - обрезка символов

## 🛠️ Сборка и использование

### Компиляция библиотеки

```bash
cd src
make s21_string.a
```

### Запуск тестов

```bash
make test
```

### Генерация отчета покрытия

```bash
make gcov_report
```

### Полная сборка

```bash
make all
```

### Очистка

```bash
make clean
```
